# nxbxa 自动玩 网页版

7 个微恐关（床下有人 / 楼梯之下 / 不要出声 / 无限流BOSS / 凶手不是我 / 笼中之物 / 人为刀俎）
随机顺序 · 无限循环自动玩。

本仓库只有我们自己的几行代码；游戏本体（引擎、启动脚本、素材、285 个关卡包）
全部打开时从官方 CDN 现拉，`hook.js` 负责把需要改的两个脚本就地打补丁：

| 补丁 | 打在哪 | 作用 |
| --- | --- | --- |
| 远程配置地址 | `assets/main/index.<ver>.js` | 改成同目录的 `nxbxconfig.json`，7 个微恐关排最前 |
| `G.isunlock` 白名单 | 同上 | 这 7 关默认解锁，其余关卡照旧 |
| 直播设置锁定 | 同上 | 4 个绿勾：道具随机 / 最后判定胜负 / 自动翻页（5 秒）/ 关卡无限时间 |
| 关卡名字 | `assets/stagebg/index.<ver>.js` | 关卡内青条上方显示「关卡名字：XXX」 |

改规则记得把 `hook.js` 里 `CFG.cacheName` 的版本号 +1，否则浏览器会继续用老缓存。
